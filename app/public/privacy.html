Privacy Policy

Effective September 29, 2026

Family Tree stores the account details and family information you provide so you can create, edit, share, and publish family trees.

Information we process

This may include your name, email address, authentication information, TLink ID, family-member names and relationships, permanent internal person identifiers, uploaded photographs, tree-connection and collaboration settings, and GitHub publishing details when you connect GitHub.

How information is used

Information is used only to operate the service, synchronize your trees, provide sharing and publishing features, prevent abuse, and troubleshoot reliability or security issues.

Storage and sharing

Application data and private photos are stored using Supabase. Information is shared with collaborators you invite. A TLink ID reveals no profile information by itself; a tree connection is created only after the receiving account approves the request. The permission selected for that connection controls whether identity only, a branch, or collaboration is shared. A tree is made public only when its owner deliberately publishes it; review the tree carefully before publishing. GitHub receives publishing data only when you connect GitHub and request publication.

Retention and control

Tree owners may permanently delete a tree from Tree Settings. You may export a backup from the application. To request account deletion or ask a privacy question, open an issue in the project repository linked below. Requests may require identity verification.

Service providers

The service relies on Supabase for authentication, database, file storage, and backend functions; GitHub for optional publishing; and Google for optional sign-in.
